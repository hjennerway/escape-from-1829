# Witby Ward

Witby Ward duplicates the current Farndon Ward, including its continuous H roof,
projecting garden gable, windows, chimneys and collision footprints. The user's
yellow-circled screenshot identifies principal OS contour edges 131..150,
southwest of Farndon. The duplicate is translated by x=-56, z=-51, retaining
the original size and orientation. This is an approximate fit to the OS range;
the existing Farndon model has longer garden wings and different small returns.
Only the superseded ward trace is retired; adjoining corridors remain visible.

Choose **Witby Ward** in Locations, or open aerial.html?view=witby,
?view=witby-plan, ?view=witby-site, or explore.html?view=witby.
It belongs to Historic and walking/gameplay, with accessible open courts.
The browser scene is updated; Unity and Blender exports are unchanged.
