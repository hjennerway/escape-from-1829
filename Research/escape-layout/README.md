# Asylum escape corridor plan

The September 17 request uses the modelled **1829 building shape**, excluding
Barmere, Redesmere and Saughall. The ward identification in
`../location-navigation/README.md` supersedes the older Redesmere photo labels:
the eastern outer range and its entire rear cross range are excluded.

`Browser/build-escape-layout.mjs` produces both navigation JSON copies. Its
41 × 33 grid compresses the existing exterior into a playable plan: the broad
cross-gallery, central reception, three separate rearward arms, two projecting
front wings and unequal end pavilions. North/rear is up on the map. The two rear
courtyard gaps remain unbuilt; there is no invented cross-gallery at their ends.
The central rear arm runs slightly farther back than the side arms.

Shape references are `escape-exterior.mjs` (core blocks),
`central-court-photo-detail.mjs` (`MAP_REAR_PROPORTIONS`), and the rear-wing
corrections in `../1829-back/README.md`. Grid dimensions, room partitions,
stair alcoves and exit positions are gameplay approximations, not a surveyed
interior. Both playable floors follow this outline. The reception stairs retain
the footage-inspired left stair and requested mirrored right stair.

Run `node Browser/build-escape-layout.mjs` to regenerate the JSON. Browser
architecture, collision, maps and pathfinding all consume those cells. The
Blender generator reads the canonical JSON; existing Blender/Unity/GLB binaries
are not regenerated by this command. Aerial compiled assets are unaffected.
