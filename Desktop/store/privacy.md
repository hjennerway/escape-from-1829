# Escape from 1829: Windows game privacy information

Prepared 27 September 2026 for the Windows version of Escape from 1829.

## Playing the game

The game runs on your computer. It has no player account system, advertising,
in-app purchases or developer-operated analytics service. Core gameplay and
historical models are included in the download and work without an internet
connection. The desktop runtime can store cached files and local browser data
in its Windows application profile. These are not sent to a developer server.

## Optional online images

Some archive wall images are loaded from www.whateversleft.co.uk and
basedinchurton.co.uk when you are online. Requesting those images sends your
IP address and ordinary web request information to those sites. Their own
privacy practices govern their handling of those requests. The game uses
fallback artwork if the images cannot be loaded. Other bundled photographs
do not require an online image request.

## Optional device location

If you select the position button, the Windows game asks permission before
requesting your device location. You can decline and continue exploring.
The game uses a location fix to show where you are near the hospital grounds.
Game code does not save a location history or send your coordinates to the
game's developer or the archive image sites.

Obtaining the fix may involve Windows or the runtime's location provider and
is subject to that provider's settings and privacy practices. Availability
depends on the device and location services. Permission granted in the
game's prompt lasts for the current session.

## Links, support and Microsoft Store

Links opened from the game use your default browser. The destination site's
privacy practices apply there. Microsoft handles Store downloads, installation
and updates under its own terms and privacy practices.

You can contact the project through
[GitHub issues](https://github.com/hjennerway/escape-from-1829/issues).
Issues are public: do not include passwords, precise location or other private
information. Information you choose to post there is handled by GitHub and
is visible to the project and other visitors.
