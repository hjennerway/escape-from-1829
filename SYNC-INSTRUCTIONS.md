# Syncing the prepared changes

1. Clone or download the repository from https://github.com/hjennerway/escape-from-1829.
2. Copy the contents of this archive over the cloned repository, replacing existing files.
3. From the `Browser` directory, run:

   ```bash
   node test.mjs
   node test-game.mjs
   ```

4. Commit and push the changed files to the `main` branch.

The archive includes the playable upstairs map, mirrored corridors and stairs, the radio-mast escape cutscene, and its reference images.
